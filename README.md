# Java

Repositório destinado ao armazenamento de exercícios, exemplos e projetos desenvolvidos durante o processo de aprendizado da linguagem Java.

O objetivo é organizar a evolução dos estudos de forma prática, reunindo implementações relacionadas a conceitos fundamentais da linguagem, lógica de programação, orientação a objetos e demais recursos do ecossistema Java.

## Organização do repositório

Cada exercício ou projeto é armazenado em uma pasta própria, permitindo uma melhor organização e acompanhamento da evolução dos estudos.
